================================================================
  Qwen3-ASR 语音转写模型 —— 需手动下载（未随仓库分发）
================================================================

本目录需要手动下载以下两个文件后放回此处：

  1. Qwen3-ASR-1.7B.Q8_0.gguf      （约 2.1 GB）  ← 主模型，必填
  2. mmproj-Qwen3-ASR-1.7B-Q8_0.gguf（约 340 MB） ← 随 GitHub Releases /
     网盘发布的 models-<版本>.zip 分发，解压后与主模型同目录

----------------------------------------------------------------
为什么 Qwen3-ASR-1.7B.Q8_0.gguf 不在仓库里？
----------------------------------------------------------------
该文件 2.1 GB，超过 GitHub LFS 单文件 2 GB 上限，无法通过代码仓库
分发。它属于 Qwen 团队发布的开源模型，请按下方指引自行下载。

提示：代码仓库只含本说明文件，不含任何 GGUF。请从发布渠道获取
models-<版本>.zip（含 llama.cpp 运行库、mmproj、FunASR），解压到
项目根目录后再按上文下载主模型。

----------------------------------------------------------------
下载方法（任选其一）
----------------------------------------------------------------

方法 A：用 HuggingFace 官方工具（推荐）
  # 安装：pip install -U "huggingface_hub[cli]"
  huggingface-cli download Qwen/Qwen3-ASR-1.7B-GGUF \
      Qwen3-ASR-1.7B.Q8_0.gguf \
      --local-dir .

方法 B：浏览器直接下载
  打开页面 https://huggingface.co/Qwen/Qwen3-ASR-1.7B-GGUF
  找到并下载文件 Qwen3-ASR-1.7B.Q8_0.gguf
  保存到本目录（与 mmproj-*.gguf 同级）

----------------------------------------------------------------
放置后的目录结构应为
----------------------------------------------------------------
models/qwen3-asr/
  ├── Qwen3-ASR-1.7B.Q8_0.gguf          ← 下载到这里
  ├── mmproj-Qwen3-ASR-1.7B-Q8_0.gguf  ← 已存在
  └── !下载模型到此处.txt

----------------------------------------------------------------
校验
----------------------------------------------------------------
下载完成后，执行 启动意向宝.bat 会自动检测并加载；缺失时
ASR 语音服务（端口 8099）将无法启动，前端会给出黄色警告。
