# 意向宝代码审核记录（2026-08-01）

## 结论

当前本地 MVP 未发现阻断发布的问题，可以提交到 GitHub。审核覆盖前端业务闭环、后端接口、认证授权、上传解析、产品平台字典、迁移与本地启动边界。

## 本轮已修正

1. 登录会话统一为 Bearer Token，移除 Cookie 回退，补充登录节流、过期会话清理和禁止缓存响应。
2. 模型设置与 Excel 字典导入仅管理员可用；普通用户、只读用户权限同时在前端导航和后端接口校验。
3. 意向字段与平台草稿改为单个事务接口，避免一半成功、一半失败；缺失平台 ID 不再被误当成新菜单内容。
4. 身份确认必须完成人工核对，并按“待确认／职能／角色／完整”级别校验必填信息。
5. 资料上传重试复用原资料包并跳过成功文件；批量意向操作只统计实际成功记录。
6. 增加录屏、录音、PDF、文本、资料包总量与磁盘余量限制，并拦截 DOCX 路径穿越和解压炸弹。
7. Windows 本地数据目录启动时收紧 ACL；源码导入不再产生数据库或演示数据副作用。
8. 技术、二级规格、三级规格筛选复用同一联动规则；竞争视角按客户和平台叶子 ID 对齐，未映射竞品不进入正式统计。
9. 模型设置网络操作串行执行，避免晚返回的旧请求覆盖新配置。
10. 密码重置批处理改用受限选项输入，避免把任意控制台文本拼接到命令中。
