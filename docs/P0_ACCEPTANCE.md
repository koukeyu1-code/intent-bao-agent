# 意向宝 P0a 初版验收边界

本轮目标不是证明真实模型效果，而是用明确标注的模拟数据跑通以下完整闭环：

> 会议资料包 → 文件预检 → 持久化处理任务 → AI 草稿 → 人工校验与确认 → 正式职能状态 → 技术/客户双视角看板 → 证据下钻与历史版本

## 2026-07-31 本地模型扩展

- 保留默认 `mock` 演示，同时增加页面化本地 Ollama 配置、连接测试和模型列表。
- API Key 为可选只写字段，仅保存在后端进程内存，重启后清除。
- TXT、MD、SRT、VTT、DOCX 和资料包备注可以进入本地 Ollama 意向抽取。
- 模型输出必须通过 JSON Schema/Pydantic 校验，且引用原话必须能在输入材料中逐字定位。
- Ollama 结果只生成“待确认”观察，不直接进入技术／客户正式看板。
- 录音、录屏和 PDF 尚未完成 ASR/OCR/视觉解析，不能据此宣称完整多模态链路已实现。

## 必须可用

1. 本地单用户运行，无需登录；SQLite 与本地文件目录持久化。
2. 创建会议资料包，记录客户、会议日期、资料属性、参会人与上传材料。
3. 显示材料格式、大小、解析状态和 PDF 配套检查结果。
4. 模拟任务必须落库，显示阶段、进度、错误信息和处理来源。
5. AI 草稿与正式状态分层保存，任何正式结论均需人工确认。
6. 支持五档态度与“未知”；采用阶段与态度分别呈现。
7. 技术视角和客户视角看板只统计人工已确认状态。
8. 每条正式状态可回溯会议、发言角色、原文、时间戳或 PDF 页码。
9. 人工修改、重新分析和补录旧会议均新增版本，不覆盖已确认历史。
10. 模拟数据覆盖 Mini LED、三模、高色域、AGLR、圆偏光、STW，23.8/27/31.5 平台及采购、开发、PM、产品、品质职能。

## 本轮边界

- `mock` 结果标注“模拟处理／演示结果”；Ollama 结果记录实际适配器和模型名，并标注为待人工确认草稿。
- 85% 为后续真实授权样本的目标，不是当前成绩。
- ASR、说话人分离、OCR、PDF/录屏对齐和多模态模型只保留适配接口。
- 不宣称已达到 60–90 分钟会议在原会议时长内处理完成。
- 不实现声纹、跨会议自动认人、实时入会、CRM/邮件/IM 接入、客户总分、成交预测、自动发布正式结论、SSO 和企业级灾备。
- 企业真实敏感数据不得调用公共模型；本轮默认仅使用模拟数据。

## 演示验收脚本

1. 打开“客户A—Mini LED—27英寸5K”会议资料包。
2. 查看采购、开发、产品、品质等职能的不同态度与证据。
3. 在 AI 洞察确认台修改一条建议并完成人工确认。
4. 返回技术视角和客户视角，看板同步显示最新确认状态和更新时间。
5. 下钻查看原始证据，并在历史页看到修改前后的两个版本。
