## 边界与缺口

**FOLLOW-31-01｜没有应用内备份、恢复、校验或保留策略（P0上线门槛）**

**FOLLOW-31-02｜性能指标尚未实测（P0试用前）**  
未测试60-90分钟、2GB录屏、100页PDF、模型显存和16GB系统内存峰值。当前mock同步流程不能代表ASR／OCR／视觉／意向模型性能。

**FOLLOW-31-03｜错误输入上限仍不完整（P1）**  
请求模型对部分文本字段有限长约束，查询 `q` 和上传文件类型内容尚缺更严格的速率、体积、解析资源和恶意压缩包防护。首期本地单用户风险较低，但真实敏感数据试用前需补足。
