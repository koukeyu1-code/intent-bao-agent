# 意向宝 · A档演示视频录制指南（2026-08-03）

> 含两部分：①录制操作（软件/参数/配音）②分镜脚本（画面+解说词）
> 数据基线：8 项新技术 + 客户A/B/C，主线为"客户A·MiniLED背光"

## 第一部分：怎么录制

### 录屏软件（选一个）

| 软件 | 优点 | 获取 |
|---|---|---|
| **OBS Studio**（推荐） | 免费、专业、可调码率 | obsproject.com |
| Windows 自带（Win+G） | 零安装 | 按 Win+G 启动游戏栏 |
| Bandicam/嗨格式 | 中文界面、简单 | 收费/有免费版 |

推荐 OBS，下面以它为例。

### OBS 推荐设置

- **分辨率**：1920×1080（1080p），别用 4K（文件太大）
- **帧率**：30fps（演示不需要 60）
- **码率**：录制 2500-4000 kbps（清晰但不至于文件爆炸）
- **格式**：MP4（兼容性最好）
- **音频**：如果现场配音就开麦克风；如果后期配音就先不录声音，只录画面
- **录制区域**：全屏浏览器（F11 全屏后录制整个屏幕）

### 录制前准备清单

- [ ] 双击 `启动意向宝.bat`，确认 `http://localhost:3000` 能打开
- [ ] 浏览器按 **F11 全屏**，Ctrl+加号放大到 **110%**（画面文字更清晰）
- [ ] 关闭书签栏、其他标签页（画面干净）
- [ ] 用 **admin** 登录（密码从本机凭据文件或密码管理器获取），所有页面都能打开
- [ ] 先空跑一遍演示流程，确认每个点击流畅无报错
- [ ] 关闭微信/邮件等弹窗通知（避免录到干扰）

### 配音方式（两种）

**方式一：边操作边解说（一次成型）**
- 戴耳机麦克风，按脚本边点边说
- 优点：省事；缺点：容易嘴瓢，可能要多录几遍

**方式二：先录画面，后期配音（推荐）**
- 先静音录完所有画面操作（分段录，后期拼接）
- 再用剪映/Audacity 录解说词，对齐到画面
- 优点：画面和声音都干净；缺点：要花点时间剪辑
- 工具：剪映（免费，自动字幕很好用）

### 文件大小预估

3 分钟 1080p 视频，约 **80-150MB**。上传视频平台前可以用 HandBrake 压缩到 50MB 以内。

### 第 3 幕：双层意向与人工确认（核心，1:15 - 2:25）

**画面操作**：
1. 点左侧「意向确认」
2. 找到客户A、MiniLED背光相关的意向观察
3. 逐条展示四个职能的不同态度：
   - **产品（赵总）**：态度5 主动推动，主动建议进入路线图

   - **品质（孙工）**：态度3 观望，可靠性数据不完整
   - **采购（李总）**：态度2 暂不支持，成本增幅需收敛
4. 重点强调：**产品推动 vs 采购暂不支持 = 内部意见分化**，系统同时保留不掩盖
5. 展示证据原话引用、五档态度徽章、置信度与态度分离

**解说词**：
> "这是意向宝的核心——双层意向模型。
>
> 第一层是 AI 从材料里抽取的原始观察。它识别每个职能对某技术的态度，五档从『明确反对』到『主动推动』。看这条：产品部赵总主动推动 MiniLED 背光进入路线图，但采购部李总暂不支持，卡在成本。同一个技术，不同职能，态度完全不同——系统都如实保留，不互相覆盖。
>
> 没有 evidence 只能判『未知』，绝脑补不出态度。模型置信度和态度档位是分开显示的。
>
> 但 AI 只是草稿。第二层正式状态，必须由产品规划负责人逐条确认。确认后生成新版本，重跑 AI 也不会覆盖。"

**镜头重点**：

## 录制注意事项

1. **操作要慢**：每点一处停 1-2 秒再说话，让评委看清，也方便后期对齐配音。
2. **不要演示的功能**（避免翻车）：
   - 不要点「模型设置」的"测试连接/读取模型"（mock 模式，非重点）
   - 不要在「数据字典」点"新增"（只在前端生效，未持久化）
   - 不要现场上传真实文件（用已有 seed 数据即可）
3. **卡住了怎么办**：暂停录制，重启服务（`停止意向宝.bat` → `启动意向宝.bat`），重录该段，后期剪接。
4. **诚实边界声明保留**：第 5 幕的"模拟数据"声明是加分项（体现工程严谨），不是减分项，别删。
5. **分段录制**：建议按 5 幕分别录制成 5 个文件，后期用剪映拼接，比一镜到底容错率高。
