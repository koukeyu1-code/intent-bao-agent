# 05－API异常与数据访问边界测试报告

## 1. 测试结论

**结论：部分实现。**

资源不存在、参数错误、格式错误、版本冲突均有稳定HTTP状态；OpenAPI可访问。资料详情和证据元数据不暴露物理路径，文件名路径穿越被清洗，受控证据下载限制在数据目录内；身份库中的真实姓名不会进入普通bootstrap响应；外部来源CORS预检被拒绝；非模拟数据不能使用mock伪造结果。

但当前仍是无认证的本地单用户API，没有角色权限和完整审计事件；任意本机调用者只要知道证据ID即可使用 `source=true` 下载原文件。该边界符合当前演示模式说明，但不满足真实数据试用或正式部署要求。

## 3. 测试环境与前置条件

- 临时SQLite和临时文件根目录。
- TestClient直接调用应用，不经过共享演示数据库。
- 动态插入一个仅存在于 `IdentityVault` 的测试真实姓名，用于验证普通查询隔离；测试结束随临时库删除。
- 证据路径越界通过临时库篡改相对路径进行，不写工作区外部文件。

## 5. 异常状态证据

```text
不存在资源：package/speaker/observation/evidence/tasks → 404
参数校验：limit=0、空标题＋非法日期                 → 422
乐观锁：package/speaker/observation                → 首次200，旧版本409
不支持格式／类型错配                               → 415
未知材料类型／未配置模型／敏感数据调用mock          → 422
路径越界                                           → 404
```

受控证据响应：

```text
GET /api/evidence/{id}/content
→ 200 application/json，返回摘录

GET /api/evidence/{id}/content?source=true
→ 200 text/plain
→ attachment; filename="minutes.txt"
→ 响应中不含物理路径
```

## 6. 缺陷、限制与建议

| 缺陷ID | 严重度 | 缺陷／限制 | 建议 |
| --- | --- | --- | --- |
| BE-CORE-018 | 高（真实试用前） | 无身份认证、角色权限；本机调用者可下载受控源文件 | 在授权真实材料试用前接入企业身份或最小本地账户；证据源文件接口做角色、资料属性和审计检查 |
| BE-CORE-019 | 高（真实试用前） | 没有完整AuditEvent和删除审计 | 对身份访问、源文件访问、导出、修改、删除、PDF例外确认和模型调用记录审计事件 |
| BE-CORE-020 | 中 | API请求模型默认忽略未声明字段 | 全部写接口使用 `extra="forbid"`，避免客户端误以为修改已生效 |
| BE-CORE-021 | 中 | 敏感数据策略目前只有“禁止mock”，尚无统一模型路由策略引擎 | 在模型调度前按资料属性白名单选择本地／企业服务；默认拒绝，记录策略版本 |
| BE-CORE-022 | 中 | 尚无文件删除、保存期限执行和受影响证据提示 | 实现软删除、影响分析、审计、恢复窗口和正式状态保留规则 |

## 7. 已确认的当前边界

- 当前是本地单用户初版；无SSO和精细权限属于公开限制，不应在比赛材料中表述为已完成。
- `IdentityVault`表已独立于普通看板查询，但尚无受控解析真实身份的服务接口。
- 模型令牌没有出现在响应和业务数据库模型中；正式接入时仍需单独执行凭证泄露扫描。
- 本轮没有测试企业内网、操作系统账户隔离、磁盘加密或生产灾备。
